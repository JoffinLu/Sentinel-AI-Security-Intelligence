SENTINEL · AI 安全知识情报系统  v1.1
=============================================
（内嵌数据库版 · 无需安装任何软件）

【运行要求】
- Windows 10/11 64 位
- 建议 8GB 以上内存、6GB 以上磁盘空间
- 无需安装 Docker、无需安装 Python、无需安装数据库

【启动】
双击 Sentinel.exe 即可：
  1. 首先出现 SENTINEL 品牌启动画面（带进度提示）
  2. 首次启动会自动初始化数据库（约 1~3 分钟，界面有说明）
  3. 完成后启动画面无缝切换为系统主界面

  首次约 1~3 分钟（取决于机器速度）；之后每次启动约 10~30 秒。
  启动期间关闭窗口即取消启动。

【关闭】
关闭系统窗口即退出整个程序（数据库自动安全停止）。
下次启动直接双击 Sentinel.exe 即可。

【LLM 配置（可选）】
系统内置默认 LLM 网关可直接使用；如需使用自己的 API Key：
  首页右上角「LLM 模型设置」→ 添加模型（如 DeepSeek/智谱/通义千问）
  → 保存并生效。支持多模型保存与一键切换。

【常见问题】
- 启动较慢：首次运行属正常（初始化数据库）；之后启动很快
- 提示"端口 5432 被占用"：本机已有其他 PostgreSQL 在运行，
  关闭它或修改 .env 中 POSTGRES_PORT 后重试
- 提示"未找到内置数据库组件"：发布包不完整，
  请重新解压压缩包（不要单独移动 Sentinel.exe）
- 提示"数据库启动失败"或长时间停留在启动画面：
  多为安全软件拦截了数据库进程（未签名程序的常见误伤）。
  程序已内置自动重试；若反复出现，请在 Windows 安全中心
  （病毒和威胁防护 → 排除项）把程序目录加入排除列表，
  或暂时退出第三方杀毒软件后启动。
- 启动画面显示错误：按提示处理后重新双击；详细日志见
  C:\Users\<用户名>\AppData\Local\Sentinel\sentinel-launch.log
  （若程序在纯英文路径下，日志在程序目录 data\ 内）
- 采集功能不工作：检查网络能否访问外网（NVD/GitHub/arXiv 等上游）

【数据位置（可在应用内修改）】
- 默认规则：
  · 程序在纯英文路径 → 数据保存在程序目录 data\ 内
  · 路径含中文（如"下载"文件夹）→ 数据自动保存在
    C:\Users\<用户名>\AppData\Local\Sentinel\
- **修改数据存储位置（推荐数据盘）**：
  1. 打开程序 → 左侧「管理」区域 → 点击「**数据存储设置**」
  2. 输入新的存储位置（可点「浏览…」直接选择文件夹）
  3. 点「保存」→ **关闭并重新打开程序**——启动时会自动把
     数据迁移到新位置（约 1~2 分钟；原位置数据会保留一份，可自行删除）
  · 要求：目标必须是**纯英文/数字路径**（数据库引擎不支持中文路径，
    程序会提示并阻止保存）
  · 想恢复默认：在设置里把位置改回"当前存储位置"并保存即可
（以上均为程序自动处理，普通使用无需任何设置。）

【数据安全】
所有数据保存在本机，不会外传。删除上述数据目录将清空数据
（重新启动会重新初始化）。
