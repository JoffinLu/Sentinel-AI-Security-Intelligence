# SENTINEL · AI 安全知识情报系统 v1.1

中国电子杯第三届高校 ICT 产教融合创新大赛 · 赛题九 参赛作品。
**免安装 Windows 打包版**——双击 `Sentinel.exe` 一键启动，数据库引擎已内嵌，
**无需安装 Docker / Python / 数据库等任何外部软件**。

## v1.1 更新内容

- **新增「拓展模块 · 网络入侵检测（ROEN）」**：移植自本团队科研项目（Computer
  Networks, 2025）的入侵检测模型——实时流量检测（GCN + LSTM 双线程，真实推理）、
  混沌加密安全响应（攻击事件 → 系统锁定 → 图像自动加密 → 口令解锁演练）
- **演示数据更新至 12,000+ 条**（情报 / 富化 / 图谱 / 问答全都有数据）
- **启动流程稳健性修复**：首次初始化数据库更可靠；本机已装 PostgreSQL 时不再阻塞；
  个别环境下启动画面卡住的问题已修复

## 启动步骤（无需任何前置安装）

1. 解压 zip，得到 `Sentinel` 文件夹（**建议放在纯英文路径**；程序已内置中文路径自动适配，任何位置都可运行）
2. 双击文件夹内的 **`Sentinel.exe`**
3. 出现品牌启动画面并自动完成初始化：
   - 首次运行：初始化数据库 + 导入演示数据（完整版），约 1~3 分钟
   - 之后每次启动：约 10~30 秒
4. 就绪后启动画面**无缝切换**为系统主界面

> 关闭窗口即退出（数据库自动安全落盘）；数据保留在本地，下次启动直接复用。
> 提示：**请勿同时运行多个副本**（共享同一数据库与端口）。
> 详细说明（FAQ / 常见问题 / LLM 配置）见压缩包内 `使用说明.txt` 或
> [仓库 README](https://github.com/JoffinLu/ICT-WB#readme)。

## 系统能做什么

- **9 类数据源自动采集**（NVD / GHSA / OSV / KEV / arXiv / POC 仓库 / 社区 RSS / ATLAS / 政策），
  三级过滤筛出 AI 安全漏洞
- **7 维精准富化**（资产 / POC / 风险 / 修复 / MITRE ATLAS / 论文关联 / CVSS 重算）
- **知识图谱 + 多轮问答**（混合检索 + 图谱多跳 + 引用溯源；图谱由内置数据库实时构建，
  无外部图数据库依赖）
- **拓展模块 · ROEN 网络入侵检测**（实时流量检测 + 混沌加密安全响应演示）
- 情报 CSV 导出 · LLM 模型管理（支持 DeepSeek / 智谱 / 通义千问等自带 Key）· 双主题界面

## 核心指标

| 指标 | 要求 | 实测 |
